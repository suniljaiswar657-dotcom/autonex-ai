# AUTONEX AI

**Your Business. Your AI. Your Autopilot.**

AUTONEX AI is a mobile-first business command center designed for small businesses, agencies, real-estate professionals, shops, and service providers.

## V1 modules

- **Overview** — business snapshot, pipeline summary, and next actions.
- **Lead Manager** — capture, search, filter, update, and export leads.
- **AI Support Desk** — prepare customer-support reply drafts for human review.
- **Marketing Studio** — create and edit reusable social-content drafts.
- **Automation Hub** — manage workflow preferences and planned automations.
- **Analytics** — review lead pipeline, won value, conversion, and follow-ups.
- **Settings** — manage local workspace preferences.

## Getting started

This V1 is a lightweight browser app.

1. Open `index.html` in a modern browser.
2. Add a test lead in Lead Manager.
3. Review the Overview and Analytics screens.
4. Try a support reply and a marketing draft.

No build step or API key is required for the current demo.

## Data and privacy

- Current demo data is stored in the browser's local storage on the device.
- Clearing browser storage or changing browsers/devices can remove or separate that data.
- This version does not provide cloud sync, multi-user access, server-side backups, or secure production CRM storage.
- Do not enter passwords, payment details, government IDs, or other sensitive information.

## Important V1 limitations

The current version is a functional front-end prototype. It does **not** connect to a live AI model, WhatsApp, email, payment gateway, social publishing service, or background automation engine. Support and marketing content is generated from local templates. Workflow switches record preferences only; they do not execute external actions. Always review drafts before sending them.
